# IGlasGAN
A generative artificial intelligence framework for the automatic inverse design of inorganic glass materials subject to box constraints on multiple coupled properties.


# Code for paper
This repository provides the core code and data for the paper <IGlasGAN: An Inverse Design Framework for Inorganic Glass Materials Based on Generative Artificial Intelligence>. If you use any related content, please cite: 
Tian, J., Zheng, J., Zhang, B. et al. IGlasGAN: an inverse design framework for inorganic glass materials based on generative artificial intelligence. npj Comput Mater (2026). https://doi.org/10.1038/s41524-026-02273-w.
